# Sistema: Calculadora de Média


***Programa para consultar média do aluno, resultando em aprovado ou reprovado***

---
## Línguagem utilizada

***Python 2026.06.06***

***

## Como executar?

1. Abra o VSCODE
2. Importe o Projeto
3. Execute o Programa

***

## Exemplo de uso

1. Digite a primeira nota: 7
2. Digite a segunda nota: 6
3. A média final é: 6.50
4. Status: Reprovado!
